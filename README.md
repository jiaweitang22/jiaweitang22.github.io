# jiaweitang22.github.io

Personal website, built with [Astro](https://astro.build) and the [Astrofy](https://github.com/manuelernestog/astrofy) template (MIT).

```bash
npm install
npm run dev
```

Pushing to `main` deploys to GitHub Pages via `.github/workflows/deploy.yml`.
Edit projects in `src/data/projects.ts`.
